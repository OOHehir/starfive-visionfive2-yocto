How to report a potential vulnerability
=======================================

Report confirmed or potential vulnerabilities in this layer on the
[Issues](https://github.com/OOHehir/starfive-visionfive2-yocto/issues) page. For
an issue that should not be public yet, report it privately through the
repository's Security tab ("Report a vulnerability") instead. Include:

- the recipe & its version
- the branch of this layer
- how to reproduce it, if known

Vulnerabilities in recipes from other layers (openembedded-core, meta-riscv) go
to those layers.

Branches maintained with security fixes
---------------------------------------

Only the default branch, `blacksail`, gets security fixes. This is a demo layer,
not a product; do not ship it unreviewed.
